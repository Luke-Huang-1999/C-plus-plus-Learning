/*
==================================================
C++ Class 實作練習 第 1 題：銀行帳戶系統
==================================================

【題目說明】

請使用 C++ 的 class 設計一個簡單的「銀行帳戶系統」。

在實際的銀行系統中，帳戶餘額不能讓外部程式直接修改，
否則可能產生不合理的資料。

例如：

    account.balance = -100000;

這種直接修改餘額的方式應該被禁止。

因此，本題請使用 class 的 private / public 機制，
將帳戶資料保護起來，並透過成員函式操作帳戶。

--------------------------------------------------
【一、類別名稱】
--------------------------------------------------

請建立：

    class BankAccount

--------------------------------------------------
【二、資料成員】
--------------------------------------------------

請建立以下三個 private 成員：

1. 帳戶編號
   型態：string

2. 持有人姓名
   型態：string

3. 帳戶餘額
   型態：double


注意：
以上三個資料都必須設為 private，
不可讓 main() 直接修改。

--------------------------------------------------
【三、建構子】
--------------------------------------------------

請建立一個建構子，使建立物件時可以直接設定：

    帳戶編號
    持有人姓名
    初始餘額

例如：

    BankAccount account("A001", "Luke", 10000);

建立完成後，account 應該具有：

    帳戶編號 = A001
    持有人姓名 = Luke
    餘額 = 10000

--------------------------------------------------
【四、deposit()】
--------------------------------------------------

請建立成員函式：

    deposit(double money)

功能：

將傳入的 money 加到目前帳戶餘額。

例如：

原本餘額：
    10000

執行：
    account.deposit(3000);

執行後：
    13000

--------------------------------------------------
【五、withdraw()】
--------------------------------------------------

請建立成員函式：

    withdraw(double money)

功能：

從帳戶餘額中提領指定金額。

但是必須進行餘額檢查：

如果目前餘額 >= 提領金額
    → 可以提款
    → 餘額扣除提款金額

如果目前餘額 < 提領金額
    → 不可以提款
    → 餘額保持不變
    → 顯示「餘額不足」

--------------------------------------------------
【六、show()】
--------------------------------------------------

請建立成員函式：

    show()

功能：

顯示目前帳戶的完整資訊。

格式可以自行設計，但至少要包含：

    帳戶編號
    持有人姓名
    目前餘額

--------------------------------------------------
【七、main()】
--------------------------------------------------

請建立一個 BankAccount 物件：

    帳戶編號：A001
    持有人：Luke
    初始餘額：10000

接著依序執行：

1. 顯示目前帳戶資料

2. 存入 3000 元

3. 顯示目前帳戶資料

4. 提領 5000 元

5. 顯示目前帳戶資料

6. 嘗試提領 10000 元

7. 顯示目前帳戶資料


--------------------------------------------------
【八、觀念要求】
--------------------------------------------------

本題必須使用：

    class
    private
    public
    建構子
    成員函式

請思考：

為什麼帳戶餘額要設計成 private？

為什麼 deposit() 和 withdraw() 要設計成 public？

為什麼建立 account 物件時，可以直接將
"A001"、"Luke"、10000 傳給建構子？

--------------------------------------------------
【九、完成後的要求】
--------------------------------------------------

完成程式後，請不要只提供程式碼。

請逐行解釋你的程式運作流程。

尤其需要解釋：

    BankAccount account("A001", "Luke", 10000);

這一行執行時：

1. 建立了什麼？
2. 呼叫了什麼？
3. 三個參數分別傳到哪裡？
4. 最後資料儲存在哪裡？

以及：

    account.deposit(3000);

執行時：

1. 找到哪一個函式？
2. money 的值是多少？
3. 哪一個變數的值被修改？
4. 修改後的結果是什麼？

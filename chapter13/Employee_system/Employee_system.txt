/*
==================================================
C++ Class 實作練習 第 2 題：公司員工系統
==================================================

【題目說明】

請使用 C++ 的 class 設計一個簡單的「公司員工系統」。

假設公司需要建立 Employee 物件，
每一位員工都有自己的：

    員工編號
    姓名
    薪資

但是公司還需要知道：

    「目前總共有幾位 Employee 物件被建立？」

這個數字不是某一位員工自己的資料，
而是屬於整個 Employee 類別的資料。

因此，本題請思考：

    什麼資料應該屬於「每一個物件」？
    什麼資料應該屬於「整個 class」？

--------------------------------------------------
【一、類別名稱】
--------------------------------------------------

請建立：

    class Employee

--------------------------------------------------
【二、資料成員】
--------------------------------------------------

請建立以下 private 成員：

1. 員工編號
   型態：string

2. 員工姓名
   型態：string

3. 員工薪資
   型態：double


另外建立一個：

    「員工總數」

這個變數必須使用 static。

請思考：

為什麼員工編號、姓名、薪資不能使用 static？

為什麼員工總數適合使用 static？

--------------------------------------------------
【三、建構子】
--------------------------------------------------

請建立建構子：

    Employee(string i, string n, double s)

建立一個 Employee 物件時：

    1. 將傳入的資料設定給該物件
    2. 員工總數增加 1

例如：

    Employee e1("E001", "Tom", 35000);

建立 e1 後：

    e1 的員工編號 = E001
    e1 的姓名 = Tom
    e1 的薪資 = 35000

而公司目前的 Employee 總數：

    1

--------------------------------------------------
【四、show()】
--------------------------------------------------

請建立成員函式：

    show()

顯示該員工的：

    員工編號
    姓名
    薪資

例如：

    員工編號：E001
    姓名：Tom
    薪資：35000

--------------------------------------------------
【五、static 函數】
--------------------------------------------------

請建立一個 static 成員函式：

    static void show_employee_count()

功能：

顯示目前 Employee 物件的總數。

例如：

    目前員工人數：3

注意：

這個函式是 static。

因此請思考：

    它應該透過哪一個物件呼叫？

還是可以直接透過 class 呼叫？

--------------------------------------------------
【六、main()】
--------------------------------------------------

請建立以下三位員工：

    E001 / Tom   / 35000
    E002 / Mary  / 42000
    E003 / John  / 38000

建立完成後：

1. 顯示 E001 的資料
2. 顯示 E002 的資料
3. 顯示 E003 的資料

接著顯示目前 Employee 的總人數。

最後使用「類別名稱」呼叫 static 函數，
顯示目前員工總數。

--------------------------------------------------
【七、重要觀念】
--------------------------------------------------

本題重點不是只有把程式寫出來。

請特別思考以下問題：

Q1：

如果有三個 Employee：

    e1
    e2
    e3

那麼：

    員工編號
    姓名
    薪資

應該是每個物件各自擁有一份，

還是三個物件共同使用同一份？

--------------------------------------------------

Q2：

如果：

    e1 的薪資 = 35000
    e2 的薪資 = 42000
    e3 的薪資 = 38000

這三個薪資顯然不能共用同一個變數。

因此這些資料應該是：

    static
還是
    non-static？

--------------------------------------------------

Q3：

假設目前建立：

    e1
    e2
    e3

我們希望知道：

    「目前總共有幾個 Employee 物件？」

這個數字是：

    e1 自己的資料？
    e2 自己的資料？
    e3 自己的資料？

還是：

    整個 Employee class 共用的一個資料？

--------------------------------------------------

Q4：

為什麼以下寫法可以成立？

    Employee::show_employee_count();

而不需要：

    e1.show_employee_count();

請用自己的話解釋。

--------------------------------------------------
【八、完成後的要求】
--------------------------------------------------

完成程式後，請不要只提供程式碼。

請逐行解釋以下程式的運作：

    Employee e1("E001", "Tom", 35000);

請說明：

1. 建立了什麼？
2. 呼叫了什麼？
3. 三個參數分別傳到哪裡？
4. 員工總數什麼時候增加？

接著解釋：

    Employee::show_employee_count();

請說明：

1. 為什麼可以直接使用 Employee？
2. 為什麼不需要建立新的物件？
3. static 函數與一般成員函式有什麼不同？

--------------------------------------------------
【限制】
--------------------------------------------------

本題請使用：

    class
    private
    public
    建構子
    成員函式
    static 成員變數
    static 成員函式

本題先不要使用：

    friend
    繼承
    virtual
    template

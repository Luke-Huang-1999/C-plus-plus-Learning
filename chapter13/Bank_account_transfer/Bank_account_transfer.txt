/*
==================================================
C++ Class 實作練習 第 3 題：銀行帳戶轉帳
==================================================

【題目說明】

請使用 C++ 的 class 設計一個簡單的銀行帳戶轉帳系統。

現在有兩個 BankAccount 物件：

    Alice 的帳戶
    Bob 的帳戶

我們希望建立一個「轉帳函數」：

    transfer()

讓 Alice 可以將自己的部分餘額轉給 Bob。

例如：

    Alice 原本有 10000 元
    Bob 原本有 5000 元

執行：

    transfer(Alice, Bob, 3000);

結果：

    Alice = 7000 元
    Bob   = 8000 元


--------------------------------------------------
【一、類別名稱】
--------------------------------------------------

請建立：

    class BankAccount


--------------------------------------------------
【二、資料成員】
--------------------------------------------------

請建立以下 private 成員：

1. 帳戶編號
   型態：string

2. 持有人姓名
   型態：string

3. 帳戶餘額
   型態：double


以上資料必須設為 private。


--------------------------------------------------
【三、建構子】
--------------------------------------------------

請建立建構子：

    BankAccount(string i, string n, double b)

建立物件時，可以直接設定：

    帳戶編號
    持有人姓名
    初始餘額

例如：

    BankAccount alice("A001", "Alice", 10000);

    BankAccount bob("B001", "Bob", 5000);


--------------------------------------------------
【四、show()】
--------------------------------------------------

請建立成員函式：

    show()

顯示該帳戶的：

    帳戶編號
    持有人姓名
    目前餘額


例如：

    帳戶編號：A001
    持有人：Alice
    餘額：10000


--------------------------------------------------
【五、friend 函數】
--------------------------------------------------

請建立一個普通函數：

    transfer()

要求：

    transfer(BankAccount& from,
             BankAccount& to,
             double money)


功能：

將 from 帳戶的 money 元轉入 to 帳戶。


例如：

    transfer(alice, bob, 3000);


執行後：

    alice 餘額 = 7000
    bob   餘額 = 8000


但是 transfer() 有一個特殊需求：

它必須直接存取 BankAccount 的 private 成員：

    from.balance
    to.balance


因此請思考：

為什麼普通的 transfer() 函數不能直接存取：

    balance


請使用：

    friend

讓 transfer() 可以存取 BankAccount 的 private 成員。


--------------------------------------------------
【六、轉帳條件】
--------------------------------------------------

transfer() 必須先檢查：

    from 的餘額是否足夠

如果：

    from.balance >= money

則：

    from.balance -= money;
    to.balance += money;

並顯示：

    轉帳成功


如果：

    from.balance < money

則：

    不可以轉帳
    from.balance 不變
    to.balance 不變

並顯示：

    餘額不足，轉帳失敗


--------------------------------------------------
【七、main()】
--------------------------------------------------

請建立：

    Alice：
    帳戶編號 A001
    餘額 10000

    Bob：
    帳戶編號 B001
    餘額 5000


建立完成後：

1. 顯示 Alice 資料
2. 顯示 Bob 資料

3. Alice 轉帳 3000 元給 Bob

4. 再次顯示 Alice 和 Bob 的資料

5. Alice 嘗試轉帳 10000 元給 Bob

6. 再次顯示 Alice 和 Bob 的資料


--------------------------------------------------
【八、重要觀念】
--------------------------------------------------

請特別思考以下問題：


Q1：

transfer() 並不是 BankAccount 的成員函式。

那麼為什麼它原本不能直接存取：

    balance


--------------------------------------------------

Q2：

如果在 class 裡面加入：

    friend void transfer(...);

代表什麼意思？


--------------------------------------------------

Q3：

為什麼 transfer() 可以同時存取：

    from.balance

以及：

    to.balance


--------------------------------------------------

Q4：

friend 函數是不是代表：

    transfer() 變成 BankAccount 的成員函式？

請判斷對錯，並解釋原因。


--------------------------------------------------
【九、完成後的要求】
--------------------------------------------------

完成程式後，請不要只提供程式碼。

請逐行解釋：

    transfer(alice, bob, 3000);

執行時的流程。


尤其要說明：

1. alice 傳入 transfer() 的哪一個參數？

2. bob 傳入哪一個參數？

3. 為什麼參數要使用：

       BankAccount&

4. money 的值是多少？

5. transfer() 為什麼可以存取：

       from.balance

       to.balance

6. 執行：

       from.balance -= money;

   時，實際修改的是哪一個物件？

7. 執行：

       to.balance += money;

   時，實際修改的是哪一個物件？


--------------------------------------------------
【十、限制】
--------------------------------------------------

本題必須使用：

    class
    private
    public
    建構子
    成員函式
    friend 函數
    reference (&)

本題先不要使用：

    static
    inheritance
    virtual
    template
